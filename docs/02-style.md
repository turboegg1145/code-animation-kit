# 02 · 风格与约束：不给约束，模型每次吐同一个屏保
这一篇讲两件事：**怎么把风格从题材里推出来**，以及**推出来之后用什么具体参数把它钉死**。
## 1. 先看清楚默认口味长什么样
调研笔记里引了 [every-frame-is-code](https://github.com/kiselas/every-frame-is-code) 的原文，它直接把模型的「屋里口味」点名了：

> a dark navy background, a neon gradient, particles "for atmosphere",
> everything moving linearly and all at once, text on top of objects,
> and crossfades as the only transition

翻译：**深海军蓝底 + 霓虹渐变 +「为了氛围」的粒子 + 所有东西同时线性运动 + 文字压在物体上 + 只会用交叉溶解做转场。** 不给约束，模型每次都吐同一个屏保。

这六条正好是六面镜子，照着自己写的东西逐条对：

| 默认口味 | 反面判据（合格线） |
|---|---|
| 深海军蓝底 | 背景色是从题材里挑的（纸色/磷光/白卡纸），不是「深色显专业」 |
| 霓虹渐变 | 色板固定 4–6 色，渐变只在表现体积/光照时出现，不做装饰 |
| 「为了氛围」的粒子 | 每个运动元素都能说出它在讲什么；说不出来就删 |
| 所有东西同时线性运动 | 有错位（`stagger`）、有缓动（`ease.*`/`spring`），且不是一起动 |
| 文字压在物体上 | 文字要么独占留白，要么有底（题签/色块），见 05 的 QA 清单 |
| 只会交叉溶解 | 硬切、压黑、网点溶解、擦除——转场本身也是内容 |
## 2. 从题材反推风格，不要从「好看」反推

| 题材 | 造型语言 | 调色板 | 字体 | 运动特征 |
|---|---|---|---|---|
| 科学史 / 古籍 | 铜版画、排线阴影、纸纹 | 泛黄纸 + 棕褐 + 一点朱砂 | 衬线 / 手写题签 + 印章 | 手绘沸腾、逐线揭示 |
| 代码 / 终端 | 位图字、扫描线、光标 | 单色磷光（黑绿） | 等宽位图字 | 打字机节奏、字符燃烧 |
| 计算机 / 数据 | 网格、坐标轴、数据条 | 白卡纸 + 黑 + 一个强调红 | 瑞士无衬线 | 硬切、精确错位、计数 |
| 像素 / 复古游戏 | 整数倍放大的低分辨率 | 16 色（如 sweetie16） | 5×7 位图字 | 逐帧跳变（不做插值） |
| 太空 / 物理 | 蓝图、苏联科普插画、木刻 | 蓝图蓝 + 白线；或木刻黑 | 工程字 + 手写标注 | 缓慢推镜、轨道弧线 |
| 工厂 / 机械 | 半调网点、网屏、套色错位 | 两到三色套印 | 粗黑无衬线 | 机械节拍、整块位移 |
| 自然 / 山水 | 分层水平线场、留白 | 墨色分层 + 一点暖色 | 题签竖排 | 横向漂移、笔触生长 |
**先选造型语言，再选颜色。** 反过来的话，你会得到一张好看的、说不出题材的图。
## 3. 调色板：4–6 色 + 角色分配
每个颜色必须有角色，没角色的颜色就是「渐变」的前身：

| 角色 | 用在哪 | 占比 |
|---|---|---|
| `bg` | 画面底色 | 50–70% |
| `mid` / 暗部 | 阴影、次要结构、网格 | 15–30% |
| `ink` | 主体、文字 | 10–25% |
| `paper` / 亮部 | 高光、反白文字 | 5–15% |
| `accent` | 焦点、强调、印章 | **≤5–10%** |
骨架里现成的四套（`assets/skeleton.html` 105–119）：
```js
const INK=Object.freeze({bg:'#e9dfc9', paper:'#f3ecdb', ink:'#2b2620', mid:'#8a7a60', light:'#fbf7ee', accent:'#a33028'});
const P16=['#1a1c2c','#5d275d','#b13e53','#ef7d57','#ffcd75','#a7f070','#38b764','#257179',
           '#29366f','#3b5dc9','#41a6f6','#73eff7','#f4f4f4','#94b0c2','#566c86','#333c57'];
const POS=Object.freeze({bg:'#f2f0eb', ink:'#111111', mid:'#7d7d7d', red:'#e3242b', white:'#ffffff'});
const PHO=Object.freeze({bg:'#030603', mid:'#175c17', lit:'#5fdc5f', hi:'#c8ffc8', white:'#ffffff'});
```
调研笔记里那部 24 秒成片用的三套（同一思路的另一种落地，注意强调色和骨架里的略有差异）：
```
Engraving   #efe6d2  #3b3226  #8a7a60  #fbf7ee  #9e2b25
Swiss       #f2f0eb  #111111  #7d7d7d  #ffffff  #e3242b
Phosphor    #020402  #0a1a0a  #1f7a1f  #b6ffb6  #ffffff
```
**强调色 ≤5–10% 怎么验**：别靠眼睛，用一次拉片数格子（大块面积目测到 1/10 是能做到的），或者干脆在代码里数面积——所有用 `accent` 画的矩形/圆，面积加起来除以 `LW*LH`。骨架里的做法更省事：强调色只在「某个条件达成之后」才出现（`p>0.99 ? accent : mid`），天然不会铺满。
## 4. 阴影不是黑
`rgba(0,0,0,0.3)` 是模型默认的阴影，它会让画面发灰发脏。三条替代：

1. **用中间调色**：纸上的阴影用 `INK.mid`（`#8a7a60`），不是灰也不是黑。
2. **暖光给冷影**：光源偏暖时，阴影往补色方向偏一点，别只压亮度。
3. **用纹理代替透明度**：版画的阴影用 `hatch()` 排线，印刷的阴影用 `halftone()` 网点。同一个「暗」，一个是线条密度，一个是网点大小，都比 alpha 更有质感。
```js
hatch(g, x0,y0,x1,y1, LH*0.012, Math.PI/4, {color: INK.mid, alpha: 0.55});   // 45° 排线阴影
halftone(g, x, y, w, h, LH*0.010, INK.mid, 0.5);                              // 网点灰阶
```
## 5. 缓动：线性是「没做决定」的同义词
骨架里的缓动表（`ease`，`assets/skeleton.html` 68–76）：

| 曲线 | 数学 | 用在哪 |
|---|---|---|
| `ease.out` | `1-(1-t)³` | 通用出场：元素从外面进来 |
| `ease.out4` | `1-(1-t)⁴` | 更利落；stagger 的默认曲线 |
| `ease.outExpo` | `1-2^(-10t)` | 扫入、揭示、擦除：起步极快、尾部极慢 |
| `ease.in` | `t³` | 离场、蓄力（东西被吸走） |
| `ease.io` | 三次对称 | 画面**内部**的移动（起点终点都在画面里） |
| `ease.back` | 带 1.70158 的过冲 | 有性格的弹入（卡片、印章） |
| `spring(t,zeta=0.42,omega=15)` | 闭式阻尼振荡 | 标题、按钮：需要「活」一点 |
**线性的合法用法只有一种**：恒速过程——自转、传送带、走字、时间码。除此之外，线性运动会让观众感知到「这是机器在动」。
```js
// 差：所有东西一起出现，还都是线性的
const p = S.i / BEAT;
g.globalAlpha = p;

// 好：有先后（stagger）、有曲线（out4）、有位移
const p = stagger(S.i, 0, BEAT*1.2, k, total, 0.8, ease.out4);
g.globalAlpha = p;
g.setTransform(...translate(0, (1-p)*LH*0.04)...);
```
**`stagger` 的签名**（`assets/skeleton.html` 83）：
```js
function stagger(t,start,dur,i,n,spread=0.35,curve=ease.out4)
// s = start + (n>1 ? i/(n-1) : 0) * spread;  再 curve(span(t, s, s+dur))
```
* `spread` 是**总错位量，单位是拍**（0.35 拍 ≈ 175 ms，是「一批东西」的自然错位）。
* `i/n` 是第几个/一共几个；顺序要有含义（从中心向外 = 揭示，从左到右 = 阅读，从上到下 = 层级）。
* 单个物体的入场时长 `dur` 别超过总错位的两倍，否则看起来还是「一起出现的」。

**弹簧的闭式解**（不积分、可 seek）已经在 00 里给了；调参口诀：`zeta` 从 0.6 往 0.3 调是「从端庄到活泼」，`omega` 从 9 往 20 调是「从慢到快」。
## 6. 时长表：所有节奏都从 BEAT 推出来
120 BPM @30fps → `BEAT = 15` 帧 = 0.5 s，`BAR = 60` 帧 = 2 s。

| 拍数 | 时间 | 用在哪 |
|---|---|---|
| 0.25 拍 | 125 ms | 最小的反馈：闪、点击、刻度 |
| 0.5 拍 | 250 ms | 小元素入场（一个点、一条线） |
| 1 拍 | 0.5 s | 一个动作（一个词出现、一段扫入） |
| 2 拍 | 1.0 s | 一行字的**停留下限**；一张卡 |
| 4 拍 = 1 小节 | 2.0 s | 一个短句 / 一个小段落 |
| 8 拍 = 2 小节 | 4.0 s | 一个完整镜头（骨架的 `poster` 就是 8 拍） |
| 16 拍 = 4 小节 | 8.0 s | 一「段」（成片四段之一） |
三条硬规矩：

* **文字停留够读**：粗略算法「0.15 s × 字符数 + 0.5 s」。一行 12 个汉字 ≈ 2.3 s，也就是至少 5 拍。
* **硬切间隔 ≥2 拍**（1 s），否则像频闪。骨架的 `poster` 里 8 个节拍方块就是按 1 拍一格闪的。
* **越接近高潮，镜头越短；高潮前留一个停顿。** 6 秒的片子里，「停顿」至少是 0.5 拍的真静止（画面不动，但有呼吸）。
## 7. 动画十二法在代码里的落地

| 法 | 代码里的做法 | 骨架里的实例 |
|---|---|---|
| 1 挤压拉伸 | 由 `t` 决定的 scale：`g.scale(1+s, 1-s)`，`s` 是缓动函数 | 标题用 `spring` 入场时的那点纵向位移 |
| 2 预备动作 | 反向的小位移先出现（`-ease.in(span(...))`）再正向 | 朱砂横线从 `S.i=-6` 起手（第 0 帧之前就在动） |
| 3 演出 / 布局 | 一个焦点、留白、对比（`SAFE`、极淡网格、单一强调色） | `poster` 的 0.07 网格 + 一条朱砂线 |
| 4 顺画 vs 摆姿势 | **纯函数只能摆姿势**：先定关键姿态，再插值 | `span()` + `ease` 就是这个模式 |
| 5 跟随 / 重叠 | `stagger()` 错位 | `dots` 里由中心向外的网点 `stagger(S.i,-5,BEAT*1.2,d*10,10,1.0,ease.out)` |
| 6 缓入缓出 | `ease.io` / `ease.out` / `spring` | 相机 `camPush` 的对数插值 |
| 7 弧线 | 二次贝塞尔或抛物线分量：`x(t)`、`y(t)` 分开写 | 飞散方块（抛物线位移 + 3 子帧模糊） |
| 8 次要动作 | 小幅、低频、一直在动 | 页脚的节拍方块、`S.post.grain` 颗粒 |
| 9 时间控制 | `BEAT` 网格 + 上面的时长表 | 段落长度全是 `BEAT` 的整数倍 |
| 10 夸张 | `ease.back` 的过冲、字号/位移的比例夸张 | `spring(t,0.55,9)` 的标题弹入 |
| 11 立体感 | 线宽一致、层次分明、排线方向统一 | `hatch` 45°、`ridgePts` 分层 |
| 12 魅力 | **一致性**：字体、色板、缓动曲线家族、转场方式在整片里不换 | 四段各有一套色板，但都是 5–6 色 + 单强调色 |
## 8. 约束就是风格
把「模型最不会做的决定」直接拿走，只留它做得好的（构图、节奏、形状）：

| 约束 | 拿走了什么 | 留下了什么 |
|---|---|---|
| 16 色（如 sweetie16） | 渐变、辉光、无意义的细节 | 色块的对比与节奏 |
| 240×135 逻辑分辨率 | 细碎的抖动 | 大形状、大动作 |
| 整数倍放大 | 重采样带来的模糊 | 硬边（复古感） |
| 单一强调色 ≤10% | 花哨的配色 | 观众的眼睛知道该看哪 |
| 一个字体家族 | 排版上的即兴发挥 | 层级（大小/粗细/字距） |
**整数倍缩放对照表**（都要正好落在 1920×1080）：

| 逻辑分辨率 | 放大倍数 | 一格像素 = |
|---|---|---|
| 160×90 | ×12 | 12×12 |
| 240×135 | ×8 | 8×8 |
| 320×180 | ×6 | 6×6 |
| 480×270 | ×4 | 4×4 |
| 640×360 | ×3 | 3×3 |
像素段落在代码里的做法：逻辑坐标里按小尺寸画，输出时整数放大，且 `imageSmoothingEnabled=false`。骨架里 `pixText` 就是这套（`g.imageSmoothingEnabled=false` + `cell` 整数倍），所以你不用自己写重采样。
## 9. 相机规则
```js
function camPush(g,t,from,to,tx=0,ty=0){
  const z = Math.exp(lerp(Math.log(from), Math.log(to), t));   // 对数插值
  g.translate(CX+tx, CY+ty); g.scale(z,z); g.translate(-CX,-CY);
}
```
* **必须在对数空间插值**。线性插值 zoom 的观感是「近处猛冲、远处在爬」。
* **一秒内别移动超过画面的 20%**。换算：整段 4 秒最多推 1.8 倍；骨架的 `poster` 整段只推 6%（`camPush(g,P,1.0,1.06)`）——**慢到几乎看不出来，但它让静止帧不死**。
* **大行程留 18 帧（0.6 s）的加减速**，别让镜头突然停。
* **别同时推拉 + 旋转 + 位移**。一次只做一件事；要换动作就先停。
* 铺底的矩形要比画面大（骨架里是 `-200,-200,LW+400,LH+400`），否则推近时四边会露出画布外的黑。
## 10. 静止帧的最小生命
**超过 1.5–2 秒完全没有变化 = 死了。** 最小生命只要 0.5–1.5% 的幅度：

| 手法 | 代码 | 周期 |
|---|---|---|
| 呼吸缩放 | `camPush(g, 0.5-0.5*Math.cos(S.i/BEAT*0.6), 1.0, 1.012)` | 3–5 秒 |
| 背景漂移 | 底纹 x 偏移 `+ S.nz.r(-0.3,0.3)` 或整段线性漂移 | 一直 |
| 颗粒抖动 | `S.post.grain` 本来每帧都变（`hash(S.seed,'grain',S.f)`） | 每帧 |
| 光标 / 指针闪烁 | `Math.floor(S.i/(BEAT*0.6))%2` 之类的低频方波 | 0.3 s |
| 次要元素的持续运动 | 页脚节拍方块、背景里的缓慢扫描线 | 1 拍 |
骨架的两段演示都自带最小生命：`poster` 有整段 6% 的推镜 + 颗粒；`dots` 有颗粒 9 + 暗角 0.34。
## 11. 排版：四种画字方式怎么选

| 工具 | 观感 | 用在 |
|---|---|---|
| `vText(g,str,o)` | 矢量、锐利、可任意字号 | 标题、正文、任何要「正式」的字 |
| `pixText(g,str,o)` | 位图、硬边、整数倍放大 | 终端、OSD、复古界面、小字 |
| `glyphs(str,o)` | 只取位图字形（要自己摆） | 逐字动画（一个字一个字飞进来） |
| `glowText(g,str,o)` | 内芯 + 大光晕 | 深底上的发光字（一层模糊是扁的） |
排版规矩：

* **字号下限**：正文不小于 `LH*0.030`（1080 短边 → 约 32 逻辑像素）；标题 `LH*0.12–0.17`。
* **一行别太长**：拉丁 ≤40 字符，中文 ≤22 字。超了就断行，别缩字号。
* **中文用 `F_CJK`**：`const F_CJK='"Noto Sans CJK SC","Noto Sans SC","WenQuanYi Micro Hei","DejaVu Sans",sans-serif';`，并且系统必须装了中文字体（见 03）。**字体缺失时 canvas 不报错，直接画空白。**
* **对齐要量**：用 `textW(g,str,size,weight,font)` 量宽度，再决定居中/右对齐，别目测。
* **安全区**：文字与主体别越过每边 7%（`SAFE`）；底线是每轴中央 92%。
## 12. 定稿前的风格自查

| 检查项 | 合格线 |
|---|---|
| 背景色 | 能从题材解释，不是「深色显专业」 |
| 色数 | 4–6 色，每色有角色 |
| 强调色占比 | ≤5–10%，且只在焦点出现 |
| 阴影 | 不是 `rgba(0,0,0,x)`；用中间调或纹理 |
| 缓动 | 除了恒速过程，没有线性运动 |
| 错位 | 成组元素用 `stagger`，顺序有含义 |
| 静止 | 没有任何 1.5–2 秒完全没有变化的画面 |
| 相机 | 对数插值、每秒 ≤20%、一次只做一个动作 |
| 排版 | 字号 ≥`LH*0.030`、行宽受控、中文用 `F_CJK` |
| 一致性 | 字体家族 / 色板 / 曲线家族 / 转场方式在整片里不换 |
